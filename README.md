# PottyPath

Free potty training readiness quiz: 8 questions score physical, thinking and emotional readiness, then build your phased potty plan timeline.

## Features
- Readiness quiz across physical, cognitive and emotional domains with a clear verdict
- Personalized phased action timeline (prep, launch days, habit, maintenance) with checkable steps
- Regression and accident troubleshooting guidance with a printable plan
